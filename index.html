About the project

Shelter listings are written for everyone, but adoption is an emotional decision made from those words. This project reads each listing twice — once in a conventional listing voice, once in a voice generated from that dog's own record. Same words. Two readings.

Every word of every listing is reproduced verbatim from the shelter. Not one word is ours.

How it works

  1. 01 Listings come from Petfinder and Oregon Humane Society, captured 2026-08-16.
  2. 02 A documented function turns each record's attributes into an ElevenLabs Voice Design prompt.
  3. 03 You listen to both readings and decide what you hear.

Flat is ElevenLabs' stock voice “Roger”, described by ElevenLabs as charismatic, positive and conversational — the register shelter marketing is already written in. Both readings use Eleven Multilingual v2. Audio is pre-generated, so this page makes no API calls and holds no keys.

Note

These are real dogs who were waiting for real homes. If you are ready to adopt, contact the shelter directly — every record links to its source.

No shelter publishes an intake date, so no dog's own voice carries a weariness modifier. Weariness appears in one place only: Yuji's stay dial, which demonstrates what the function does with that variable rather than reporting a real stay. We can hear what waiting does to a voice; we cannot tell you how long any of these dogs has actually waited.
