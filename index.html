The Waiting Room

Eight real shelter dogs. Every listing is read twice — once by a flat institutional voice, once by a voice generated from that dog's own record. Not one word of the text is ours.

The shelters write from a template: the same sentences appear in listing after listing. Where two dogs share a sentence, you can hear both read it.

The flat reading is ElevenLabs' stock voice “Roger” — described by ElevenLabs as charismatic, positive and conversational. It is not a monotone robot; it is the upbeat register shelter marketing is written in. The designed reading was generated with ElevenLabs Voice Design from a prompt built by buildVoicePrompt(), which reads the shelter's own record. Both use Eleven Multilingual v2. The contrast is one of tone, not of expressiveness.

Audio is pre-generated and committed, so the page makes no API calls and holds no keys.

No shelter publishes an intake date. Not one of these listings says how long the animal has been waiting, so days_in_shelter reads unknown on every card and no dog's own voice carries a weariness modifier. Weariness appears in one place only — the stay slider, which demonstrates what the function does with that variable rather than reporting a real stay. We can hear what waiting does to a voice; we cannot tell you how long any of these dogs has actually waited.

Listing text is reproduced verbatim and was captured 2026-08-16; these dogs may already be adopted. The voices are an interpretation of a record, not a measurement of an animal.
